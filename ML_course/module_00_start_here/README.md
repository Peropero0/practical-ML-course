# Module 0 · Start here

One notebook, `00_start_here.ipynb`, to open **before anything else**. It checks that your Python and your libraries are ready, checks the datasets, and lets you try an exercise check on a two-line example so you know how the exercises work.

Run it from top to bottom (Run All). It changes nothing in the course. If it reports a problem, follow the installation steps in the README at the root of the project (virtual environment or Docker), then run it again.
